Antes de empezar

  • Se necesita permiso de acceso para editar el vídeo.
  • El proveedor de transcripción debe estar configurado en la configuración de administrador del sistema.
  • El vídeo debe estar disponible para procesamiento (no eliminado/con error).

Paso 1 – Acceder a la configuración del vídeo

  1. Acceda a Gestión de vídeos.
  2. Abra el vídeo deseado en la página de Configuración del vídeo.
  3. Desplácese hasta el área de Subtítulos.

Paso 2 – Crear transcripción automática

  1. Pulse el botón Crear transcripción de nuevo.
  2. El sistema encola la solicitud en segundo plano (Queue).
  3. El proceso continúa a través del mecanismo Cron del sistema.
No es necesario esperar en la misma pantalla hasta que termine. Puede seguir trabajando en el sistema mientras se crea la transcripción en segundo plano.

Paso 3 – Comprobar el estado

Tras crear la solicitud, aparecerá un mensaje indicando que el sistema está trabajando en la transcripción. Estados de proceso habituales:

  • UPLOADED – la solicitud se creó y está pendiente de procesamiento.
  • INPROCESS – la transcripción está en proceso con el proveedor externo.
  • READY – la transcripción está lista y disponible para edición/visualización.
  • ERROR – hubo un error en el proceso; debe intentarse de nuevo.

Paso 4 – Edición manual de subtítulos

  1. Pulse Interfaz para crear subtítulos o Interfaz para editar subtítulos.
  2. Edite tiempos y texto según sea necesario.
  3. Guarde los cambios.

Preguntas frecuentes

Pulsé «Crear transcripción» y no hay resultado inmediato – ¿es normal?

Sí. La creación de transcripción se realiza en segundo plano mediante Cron y puede tardar varios minutos.

¿Qué hacer si el proceso se queda bloqueado?

  • Comprobar que el proveedor de transcripción esté configurado y que la clave API sea válida.
  • Comprobar que Cron esté activo en el entorno.
  • Volver a pulsar Crear transcripción de nuevo.
