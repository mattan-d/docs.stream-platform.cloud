Visión general

La página de gestión de usuarios solo es accesible para usuarios con permisos de administrador. Se accede desde el menú (por ejemplo, desde el menú de usuario – Gestión de usuarios) o en la dirección /user/admin (por ejemplo, https://dev.video/user/admin). En la página se muestra una lista de usuarios en tarjetas, filtrado por búsqueda y tipo de usuario, y acciones para cada usuario.

Nota: Un usuario que no sea administrador recibirá un error 404 o un mensaje de acceso denegado. Debe iniciar sesión como administrador.

Acceso a la página

En el menú superior (menú de usuario / perfil), seleccione Gestión de usuarios. La opción solo aparece para administradores.

Filtros (barra lateral)

A la izquierda:

  • Búsqueda – campo para buscar usuarios por ID, nombre, apellidos, correo electrónico o nombre de usuario.
  • Tipo de usuario – lista: todos, administrador, usuario regular.
  • Filtrar – aplicar el filtro según los campos anteriores.
  • Restablecer – limpiar el filtro y volver a la lista completa.

Ordenación y resultados

Sobre la lista de tarjetas se muestra el número de resultados y enlaces de ordenación: ID, nombre, apellidos, correo electrónico, último acceso, permiso. Al pulsar un encabezado se ordena la lista. También hay paginación arriba y abajo.

Tarjeta de usuario

Cada usuario se muestra en una tarjeta con:

  • Imagen / avatar – al pulsar se accede al perfil del usuario.
  • Nombre – nombre y apellidos; al pulsar se accede al perfil.
  • Etiqueta de estado – activo o inactivo.
  • Metadatos – ID, correo electrónico, último acceso, método de autenticación, tipo (administrador / usuario regular).
  • Acciones – iconos: eliminar, configuración de usuario, ver métricas, iniciar sesión como.
  • Eliminar – abre un diálogo para confirmar la eliminación del usuario.
  • Configuración de usuario – accede a la página de edición de los datos del usuario (perfil, permisos, etc.).
  • Ver métricas – accede a las métricas del usuario.
  • Iniciar sesión como – inicia sesión en el sistema como ese usuario (para soporte/pruebas).

Eliminación de usuario

Al pulsar el icono de eliminar en la tarjeta se abre un diálogo (modal) de confirmación. Tras confirmar, el usuario se elimina del sistema y la página se actualiza (o se muestra un mensaje de éxito). Esta acción suele ser irreversible.

Configuración de usuario y perfil

Al pulsar Configuración de usuario (icono de engranaje) se accede a la página /user/settings/{id}, donde se pueden editar los datos, activar o desactivar al usuario y gestionar permisos.
