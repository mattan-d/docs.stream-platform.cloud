Video Management

Administrators only – page for managing all videos in the system at /videos/admin.

Overview

The Video Management page is accessible only to users with administrator permissions. Open it from the menu (for example Video Management) or at /videos/admin (for example https://dev.video/videos/admin). The page shows a card list of videos, advanced filtering (status, privacy, user, channel, dates, length), sorting, multi-select, and deletion.

Note: A non-admin user will see a 404 page or an access message. Sign in as an administrator.

Accessing the page

In the top menu (user menu), choose Video Management. This option appears only for administrators.

Filtering (sidebar)

On the left:

  • Search – search by ID, title, description, path, course.
  • Status – published, archive, error, processing, pending download (or all).
  • Privacy – public, authenticated, link (or all).
  • User – filter by user (autocomplete).
  • Channel – filter by channel.
  • From date / To date – upload date range.
  • Minimum / maximum length (minutes) – video duration limits.
  • Filter – apply the filter. Reset – clear and return to the full list.
  • Actions – Export to Excel downloads a report for the current filter, and Delete from Excel permanently deletes videos from that export file (see below).

Sorting and multi-select

Above the card list: video count, Select all (check/uncheck all cards), and Sort links – date, title, status. After selecting at least one video, an actions bar appears: "X videos selected", Download button (up to 5 videos – for published videos that are not from YouTube) and Delete button (opens a dialog to confirm deletion of selected items).

Video card

Each video is shown in a card with:

  • Checkbox – for multi-delete or download selection.
  • Thumbnail and duration – clicking the image or title goes to the watch/edit page.
  • Title and status badge – published, archive, error, processing, etc.
  • Metadata – ID, source, user, upload date, size, privacy, views, captions.
  • Actions – Edit (video settings), Delete (confirmation dialog for deleting the single video).

Deletion – single and bulk

Clicking the delete icon on a card opens a dialog to confirm deleting that single video. Multi-select and clicking Delete in the actions bar opens the same dialog with a link to delete all selected items. On confirmation – videos move to the Deleted status (soft delete). Files are permanently purged only after the grace period configured in system settings.

Permanent deletion from Excel

To permanently delete a list of videos from an export file, use Delete from Excel (/videos/excel_delete). Admins only.

Important: Excel deletion is permanent. After confirmation, videos cannot be restored and files are removed immediately (no grace period).
  1. In Video management, filter the list you want and click Export to Excel.
  2. In Actions, click Delete from Excel.
  3. Upload the export file (format with a Video # column).
  4. Review the preview: counts in file, will delete, locked, missing, and estimated size.
  5. Check the confirmation box and click Delete permanently.

Locked videos are skipped. Summary rows at the end of the Excel file (for example Total Videos) are ignored automatically.

Edit and export

Clicking Edit (gear icon) goes to the Video Settings page (/videos/edit/{id}) – edit title, description, privacy, trim, and more (see Video settings). Export to Excel in the sidebar downloads a file with videos matching the current filter — the same format is used for Delete from Excel.
