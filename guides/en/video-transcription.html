Before you start

  • You need permission to edit the video.
  • The transcription provider must be configured in system admin settings.
  • The video must be available for processing (not deleted/error).

Step 1 – Open video settings

  1. Go to Video Management.
  2. Open the desired video on the Video Settings page.
  3. Scroll to the Captions area.

Step 2 – Create automatic transcription

  1. Click the Regenerate transcription button.
  2. The system queues the request in the background (Queue).
  3. Processing continues through the system's Cron mechanism.
You do not need to wait on the same screen until completion. You can continue working in the system while transcription is created in the background.

Step 3 – Check status

After creating the request, a message appears that the system is working on the transcription. Common process states:

  • UPLOADED – request created and waiting for processing.
  • INPROCESS – transcription in progress with the external provider.
  • READY – transcription is ready for editing/viewing.
  • ERROR – an error occurred; try again.

Step 4 – Manual caption editing

  1. Click Caption creation interface or Caption editing interface.
  2. Edit times and text as needed.
  3. Save your changes.

Frequently asked questions

I clicked create transcription and there is no immediate result – is that normal?

Yes. Transcription runs in the background via Cron and may take several minutes.

What to do if the process gets stuck?

  • Verify the transcription provider is configured and the API Key is valid.
  • Verify Cron is active in the environment.
  • Run Regenerate transcription again.
